Privacy. Last updated September 28, 2026.

Inflationdle has no accounts and asks for no personal information. Your guesses, stats and streak are saved only in your own browser (local storage). They never leave your device, and clearing your browser data erases them. When you finish a daily round, one small cookie (ic_done) records which of the last few days you finished, so the price history page for that item opens for you before the round ends. It holds only day numbers and expires after four days.

The site is hosted on Cloudflare, which processes standard request data such as IP address and browser type to deliver and protect the site. Visits are counted with Cloudflare Web Analytics, which does not use cookies or track you across other sites.

The live visitor counter counts each browser once a day. Your browser remembers the date it was last counted (local storage), and the server stores only a scrambled code made from your IP address and browser type mixed with a random value that changes every day. Those codes and random values are deleted after a day, so they can't be traced back to you or linked from one day to the next. Only the totals are kept. Links on our social profiles end in a tag such as ?ref=bsky, and when you arrive through one, the counter also adds one to that platform's daily tally, using the same scrambled code, so we can see which platforms bring players.

Fonts load from Google Fonts, which receives your IP address when the page loads.

The "Suggest an item" link opens a feedback form hosted by Tally. Only what you type into it is sent, and you don't need to give your name or email.

If we add advertising or an email newsletter, this page will be updated first to say what changes.
